# Економічна безпека Норвегії

Статичний вебсайт-дослідження економічної безпеки Норвегії (дані Світового банку, 2019–2023).

- `index.html` — головна сторінка (про автора)
- `analysis.html` — аналітична сторінка (таблиці, порогові значення, графіки Chart.js, висновки)
- `style.css` — спільні стилі (доповнюють Tailwind CSS)
- `script.js` — меню, анімації, графіки

Технології: HTML, Tailwind CSS (CDN), Chart.js (CDN), JavaScript. Без збірки.
